**Generated solarpunk architecture recipes**

- `solarpunk.json` describes 41 metric authoring recipes and the user reference boards.
- `neutral-series.json` defines eight house, civic and greenhouse sources. `series-runtime.json` maps them into the 42-model integrated review bank.
- `generated-buildings.json` pins each generated first draft: board, edited input image, draft and retopology tasks, metric fitting and entrance. See the [generated route](../../tools/city/README.md#generated-first-draft-building).
- Its `surface` block is the shared rule that reads a generated atlas as material classes: reference colours, allowed orientations, mullion spacing and storey height. See [generated shell surfaces](../../docs/spec-ville-procedurale.md#generated-shell-surfaces).
- The references remain in the user's Downloads folder; large assets are not committed.
- Use `tools/city/produce.py` and the [production contract](../../docs/spec-ville-procedurale.md).
- Record neural and procedural methods separately.
- A recipe or a generated candidate is not an accepted production model.
- The current composition uses shared habitat gardens and narrow pedestrian connections.
- Do not introduce private frontage subdivisions or automobile-road grids.
